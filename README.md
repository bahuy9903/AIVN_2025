# AIVN_2025

Repo này dùng để **luyện tập code Python và AI** trong quá trình học tập.

## Nội dung
- Ôn luyện và thực hành **Python cơ bản → nâng cao**
- Làm bài tập, ví dụ minh hoạ theo từng chapter/tuần
- Thực hành các chủ đề **AI / Machine Learning / Deep Learning**
- Ghi chú kiến thức và các đoạn code quan trọng

## Cấu trúc thư mục (dự kiến)
- `Chapter 1/` : Python cơ bản
- `Chapter 2/` : Cấu trúc dữ liệu 
- `AI/`        : bài tập và project AI
- `Notes/`     : ghi chú học tập

## Mục tiêu
- Nâng kỹ năng lập trình Python
- Hiểu và áp dụng các thuật toán AI
- Xây nền tảng cho các project lớn hơn sau này
